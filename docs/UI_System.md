# StageFront UI System

Version: 1.0

## Layout

- Mobile-first responsive design
- Maximum content width around 1280px
- Generous vertical spacing
- Fixed or sticky navigation with a dark translucent background

## Buttons

Primary buttons use Stage Gold, Stage Black text, a rounded shape, and visible hover and keyboard-focus states.

Secondary buttons use a transparent or dark background with Spotlight White borders and text.

## Cards

- Dark surface distinct from the page background
- Subtle border and moderate corner radius
- Restrained shadow or glow
- Image, category, title, supporting detail, and one clear action

## Motion

- Favor fades, short translations, and gentle spotlight movement.
- Respect reduced-motion preferences.
- Avoid continuous motion that distracts from content.

## Image Handling

- Use Next.js image optimization for content imagery.
- Keep critical text outside images.
- Provide responsive sizes and meaningful alternative text.
- Use stable paths defined in the asset manifest.
